# NUCODE NU40-DK V2 핀 배정 / 하드웨어 참고

## 보드
- 칩: Nordic nRF52840 (Cortex-M4F 64MHz), 모듈 NCRB40N01VC
- 무선: BLE 5.4, IEEE 802.15.4 (Thread/Zigbee). 와이파이 없음
- USB: USB-C → ESD(USBLC6-2P6) → nRF52840 네이티브 USB 직결 → **USB HID 가능**
- 부트로더: UF2 (드래그앤드롭)

## 전원
- 충전 IC: BQ25186 (I2C 0x6A, SDA/SCL = P0.26/P0.27)
- 배터리 커넥터: J2, 1.25mm 간격. **극성 확인 필수 (빨간 선 = +)**
- 3.3V 레귤레이터: AZ1117-3.3 (VSYS → 3V3_SYS → VDD_MOD)
  - 배터리 단독 구동 시 3V3 핀이 3.3V보다 낮을 수 있음 → 실측 필요
- 배터리 전압 측정: P0.02 (VBAT_MON, 470K/1M 분압)
- VEXT: 5~12V 외부 입력

## I2C (Qwiic 공유 버스)
- SDA = P0.26, SCL = P0.27 (4.7kΩ 내부 풀업)
- 주소: 충전IC 0x6A, MPU6050 0x68, OLED(SSD1306) 0x3C → 충돌 없음

## 온보드 버튼 / LED
- 버튼(내부 풀업, 누르면 LOW): S1=P0.11, S2=P0.12, S3=P0.24, S4=P0.25, RESET=P0.18
- LED(LOW일 때 켜짐): LED0~3 = P0.13, P0.14, P0.15, P0.16

## 피해야 할 핀
P0.18(리셋), P0.00/P0.01(32.768kHz 크리스털), P0.02(배터리 측정),
P0.26/P0.27(I2C), P1.00(디버그 SWO), P0.09/P0.10(기본 NFC, GPIO 전환 시 설정 필요)

## 자유 사용 후보
P0.03~P0.08, P0.17, P0.19~P0.23, P0.28~P0.31, P1.01~P1.15
(P1.03~P1.05는 충전 IC 신호용이나 기본 미연결 → 사용 가능)

## 컨트롤러 A (메인) 핀 배정안

| 기능 | 핀 | 비고 |
|---|---|---|
| I2C SDA / SCL | P0.26 / P0.27 | MPU6050, OLED, 충전 IC 공유 |
| 데드맨 누름 | P0.11 (S1) | 외부 스위치 병렬 (같은 핀·GND) |
| 슬라이드 상승 | P0.03 | 내부 풀업, GND로 단락 |
| 슬라이드 하강 | P0.04 | 내부 풀업, GND로 단락 |
| 복귀 버튼 | P0.24 (S3) | 외부 스위치 병렬 |
| UxV 전환 버튼 | P0.25 (S4) | 외부 스위치 병렬 |
| 진동 모터 (PWM) | P0.28 | 트랜지스터 베이스 |
| 리드 스위치 (선택) | P0.29 | 장착 위치 감지 |
| 배터리 잔량 | P0.02 | 보드 내장 분압 |
| 상태 LED | P0.13~P0.16 | 온보드, 디버깅용 |

전략: 온보드 버튼(S1~S4)으로 먼저 기능을 검증하고, 이후 외부 스위치를 같은 핀에 병렬로
추가하면 코드 수정 없이 하드웨어만 바꿀 수 있다.

## 통신 구조

- **시뮬레이터(1단계)**: 보드 — USB — 맥, TinyUSB HID 게임패드로 인식 → FPV Freerider
- **UGV(3단계)**: 보드 — BLE GATT notify — 라즈베리파이(Python bleak)
  - 전송: 피치, 롤, 요 회전속도, 데드맨 상태, 슬라이드 상태, 버튼 이벤트, 초당 30~50회
  - 페일세이프: 0.3초간 신호 없으면 즉시 정지
