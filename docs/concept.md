# 운용 개념 / 발표 근거

## 자율 수준

- **HOTL (Human-on-the-Loop)**: 평상시. UAV/UGV가 자율적으로 병사를 따라오며 표적 탐지.
- **HITL (Human-in-the-Loop)**: 병사가 데드맨을 눌러 잠시 수동 조종. 특정 목표를 직접 확인하고 싶을 때.
- **HOOTL은 의도적으로 배제**: 표적의 확인·판단은 항상 사람. 무장/발사 기능은 제안에서 제외
  (교전은 별도 인증 절차를 거치는 체계로 분리한다고만 언급).

발표 메인 틀은 이 세 단계. 보조 근거로 JARUS 자동화 수준 인용:
- 평상시 = 4단계 (예외 관리)
- 수동 개입 = 2단계 (작업 부담 경감: 기계가 자세 안정·회피·통신두절 정지를 분담)
→ 완전 수동이 아니라 빨리 익힐 수 있다는 근거. JARUS도 온더루프→인더루프 전환의
인간공학적 설계를 핵심으로 언급함.

학술 용어: 가변 자율성 (adjustable / sliding autonomy). 핵심 가치는 HOTL↔HITL
**전환 순간의 인터페이스**다.

## 실사례 비교

- 한화 아리온스멧: 2026년 한국 육군 첫 다목적무인차량 선정. 병사 추종 + 원격조종 +
  통신두절 시 자동복귀.
- Skydio X10D: 미 육군 단거리정찰 드론. 자율비행·추적, 서드파티 조종기 지원.

## 차별점

기존 체계는 수동 전환 시 별도 조종기/태블릿이 필요. 이 장치는 총을 든 채 즉시 전환.
DJI 모션 컨트롤러는 고글로 시야를 뺏기지만, 이 장치는 맨눈 전방 경계를 유지한다.

## 실험 설계 (발표용 데이터)

- 메인 비교: 엑스박스 블루투스 컨트롤러(양손 두 스틱) vs 이 컨트롤러
- 시뮬레이터: FPV Freerider, Self-level/Angle 모드, 두 조종기 동일 설정
  - 고도 유지 기능이 없어 데드맨 뗄 때 "호버링 스로틀 값"을 보내 호버링 흉내
  - **HITL 구간(수동 개입)만 재현**, 자율 추종(HOTL)은 범위 밖임을 명시
- 표준 코스: 이륙 → 게이트 통과 → 지정 지점 호버링 → 착륙
- 참가자 5~8명, 두 조종기 모두 사용(순서 교차), 조종기당 같은 코스 3회 (1인 약 15분)

| 지표 | 보여주는 것 |
|---|---|
| 회차별 완주 시간 | 학습 곡선 |
| 게이트 놓침·충돌 횟수 | 조종 정확도 |
| 주변 신호 인지율 (이중 과제) | 조종 중 경계 유지 (핵심 주장) |
| NASA-TLX | 인지부하 |

이중 과제: 비행 중 실험자가 옆에서 무작위로 숫자 카드/LED 제시 → 참가자가 소리 내어
말함 → 놓친 횟수 기록. 시간 남으면 진동 피드백 유/무 비교도 추가.

"게임"이 아니라 "비행 시뮬레이션 테스트 환경"으로 표현하고, 결과는 표/그래프 중심으로 제시.

발표 흐름: 시뮬레이터 비교 데이터 → 같은 컨트롤러를 총에 단 채 실물 메카넘 UGV로
모서리 파이슬라이싱 시연 (+ 백업 영상).
